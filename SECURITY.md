# Security Policy

## Supported Versions

Security fixes target the latest version on the default branch until formal releases are established.

## Reporting a Vulnerability

Please do not open a public issue for vulnerabilities that could expose user data, API keys, or private browsing content.

If this repository has private vulnerability reporting enabled, use GitHub's private reporting flow. Otherwise, open a minimal public issue that says you have a security report to share, without including exploit details.

## Sensitive Data

BrowserMate AI can send page content to the AI endpoint configured by the user. Changes that affect what data is sent, how API keys are stored, or which origins can be accessed should receive extra review.
